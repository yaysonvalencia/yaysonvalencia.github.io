# Yayson Valencia — Professional Portfolio

Executive-oriented portfolio for enterprise operations, business strategy, analytics, and applied AI.

Target: https://yaysonvalencia.github.io

## Architecture

Buildless HTML and CSS without a JavaScript runtime. No package installation, backend, visitor tracking, remote fonts, or API keys. All content and navigation use standard browser features.

- `index.html`: professional overview, selected work, approach, background, contact.
- `case-studies/`: three independently addressable case studies.
- `assets/`: shared styles, monogram favicon, social preview, and dashboard image.
- `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`: hosting and discovery.
- `docs/`: evidence review, content rules, publication and maintenance steps.

## Preview locally

Run `python -m http.server 8000` from this directory. Open http://localhost:8000.

## Publish

Use this repository only for the website. Keep the separate `yaysonvalencia` profile repository and project repositories unchanged. See `docs/PUBLISHING.md`.

## Content rules

Case studies distinguish completed artifacts, observations, proposed applications, and unmeasured outcomes. Program projects retain their attribution. Synthetic data is labeled. Never present dataset revenue or dashboard metrics as client impact.

The dashboard image is a render of page 2 of the original public NovaTech dashboard PDF. No values were altered. Home-page brief and pipeline panels are labeled HTML summaries, not screenshots of additional software.

## Editing

Edit HTML directly for copy; edit `assets/styles.css` for visual design. Keep evidence links, limitations, page titles, descriptions, and sitemap in sync. Review education status and contact destination before significant updates. Personal career statements come from the owner; project details come from the public artifacts reviewed on November 20, 2026.
