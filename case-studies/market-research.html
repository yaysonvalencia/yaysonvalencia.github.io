The business decision

How can analysts compare metropolitan indicators without repeatedly rebuilding data collection and quality checks?

This independent reference implementation provides a configurable research foundation: retrieve public data, normalize geography, calculate transparent indicators, and export evidence that another analyst can inspect.

My contribution

I developed and documented the reference pipeline, including Census API ingestion, CBSA normalization, transformations, missing-data handling, quality reporting, descriptive outputs, and a run manifest.

The repository is a general-purpose exploratory tool. It does not contain client deliverables or constitute an investment recommendation engine.

The analytical approach

  1. Configure the research. Select metropolitan CBSA codes, indicators, and an ACS source vintage.
  2. Retrieve and normalize. In live mode, request ACS data with timeouts, retries, schema checks, and geographic code matching.
  3. Validate and transform. Convert negative Census sentinel values to missing data, check denominators and rate bounds, and preserve indicator-level quality flags.
  4. Export a reproducible record. Produce indicators, quality statuses, a data dictionary, summary statistics, a descriptive chart, and a run manifest.
The central control: identify the source and the mode.

The default demo output is synthetic. A separate live-data manifest identifies the Census source, 2024 ACS vintage, selected markets, and a non-synthetic run.

Demonstrated result

The published live-data example covers Austin, Denver, and Minneapolis–St. Paul across six indicators. Its run manifest records 18 OK quality statuses. This indicates non-missing outputs passing the implemented checks; it does not certify statistical accuracy or investment attractiveness.

Limits and next validation

  • ACS sampling margins of error are not integrated. Adding them would strengthen comparison and interpretation.
  • Housing vacancy means all vacant housing units divided by total units; it is not rental vacancy.
  • ACS unemployment differs from BLS LAUS unemployment. Median owner-occupied home values are not transaction prices.
  • The reference uses one source vintage and does not establish longitudinal comparability, predictive accuracy, or market attractiveness.
  • The optional BLS occupation module has a different statistical universe and must be interpreted separately.

Further decision support would require uncertainty estimates, additional demand and risk evidence, and a documented comparison framework suited to the business question.
